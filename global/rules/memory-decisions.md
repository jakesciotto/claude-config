# memory-decisions.md

Dated log of decisions made during sessions. Each entry documents a choice with enough context to understand why it was made.

Format: `### YYYY-MM-DD - Decision title` followed by a brief description.

**Scope rule.** This file is loaded into *every* session, in every project, so it holds only decisions that are cross-project or machine-level. Project-specific decisions belong in that repo's `.claude/project/decisions.md`. Keep entries short; if an entry needs more than ~10 lines it belongs in a project file or an archive.
